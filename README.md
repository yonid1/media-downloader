# מוריד מדיה — תוסף לכרום

- מזהה קבצי וידאו ואודיו בעמוד שאתם גולשים בו ומוריד אותם בלחיצה.
- מוריד סרטונים ושירים מאתרי וידאו (דרך yt-dlp), כווידאו (MP4) או כאודיו (MP3).
- מדלג על פרסומות בזמן צפייה.

## התקנה

> חשוב: כרום מריץ את התוסף מתוך התיקייה עצמה. שימו את התיקייה `media-downloader` במקום קבוע (למשל בתוך "מסמכים") לפני ההתקנה, ואל תמחקו או תעבירו אותה אחר כך.

1. פתחו בכרום את הכתובת `chrome://extensions`
2. הפעילו למעלה מימין את **מצב מפתח** (Developer mode)
3. לחצו **טעינת פריט לא ארוז** (Load unpacked) ובחרו את התיקייה `media-downloader`
4. נעצו את התוסף בסרגל (סמל חתיכת הפאזל ← נעץ)

אם כבר טענתם גרסה קודמת של התוסף, הסירו אותה וטענו מחדש (לגרסה החדשה יש מזהה קבוע).

## הורדה מאתרי וידאו — התקנה חד־פעמית

אתרי וידאו גדולים לא שולחים את הסרטון כקובץ אחד: הווידאו והאודיו מגיעים בנפרד, בחתיכות, והכתובות שלהם מוצפנות ומשתנות. הכלי החינמי והפתוח [yt-dlp](https://github.com/yt-dlp/yt-dlp) יודע לפענח את זה, והתוסף מפעיל אותו בשבילכם.

1. אם אין לכם Homebrew, התקינו אותו לפי ההוראות באתר https://brew.sh (פקודה אחת בטרמינל, תתבקשו להקליד את סיסמת המחשב).
2. בטרמינל, הריצו:
   ```
   bash "<הנתיב לתיקייה>/media-downloader/install.sh"
   ```
   הסקריפט מתקין את yt-dlp, את ffmpeg (מחבר וידאו ואודיו וממיר ל-MP3) ואת deno (שחלק מהאתרים דורשים), ומחבר אותם לכרום.
3. ב-`chrome://extensions` לחצו על סמל הרענון של התוסף.

הסקריפט מעתיק את הגשר ל-yt-dlp אל `~/Library/Application Support/MediaDownloader`, כי macOS לא נותן לכרום להפעיל תוכנות מתוך "מסמכים". אם התוסף מתעדכן, הריצו שוב את `install.sh`.

מדי פעם אתרים משנים דברים ו-yt-dlp צריך עדכון. אם הורדות מתחילות להיכשל, הריצו `brew upgrade yt-dlp`.

## שימוש

- **הורדת סרטון או שיר**: בדף של סרטון, לחצו על סמל התוסף ← **הורד וידאו (MP4)** או **הורד אודיו (MP3)**. בחלון התוסף רואים את ההתקדמות, ו"הצג בתיקייה" פותח את הקובץ ב-Finder. אפשר לסגור את החלון, וההורדה תמשיך.
- **איפה הקבצים נשמרים**: macOS לא נותן לתוכנות שכרום מפעיל לשמור בתיקיית ההורדות, ולכן סרטונים נשמרים בתיקיית **סרטים** (Movies) ושירים בתיקיית **מוזיקה** (Music), בתוך תת־תיקייה בשם `Media Downloader`. הורדות רגילות של קבצים מהעמוד נשמרות כרגיל בתיקיית ההורדות.
- **חיתוך קטעי חסות**: כשהאפשרות מסומנת, קטעים שבהם היוצר מפרסם ספונסר או מבקש "לעשות לייק ולהירשם" נחתכים מהקובץ (לפי המאגר הקהילתי SponsorBlock). פרסומות של האתר עצמו אף פעם לא נכנסות לקובץ שמורד.
- **דילוג על פרסומות בזמן צפייה**: כשהאפשרות מסומנת (ברירת המחדל), התוסף לוחץ על "דלג", מריץ קדימה פרסומות שאי אפשר לדלג עליהן (בלי קול), סוגר פרסומות שקופצות על הסרטון ומסתיר מודעות בעמוד.
- **קבצים בעמוד**: כשמזוהים קבצים, מופיע מספר על סמל התוסף. לחיצה עליו מציגה את הרשימה, עם **הורד** לכל קובץ ו**הורד הכל**.
- **קליק ימני** על נגן וידאו/אודיו או על קישור לקובץ מדיה ← "הורד".

## מגבלות

- Netflix, Disney+, Spotify ושירותים דומים מצפינים את התוכן (DRM), ואי אפשר להוריד מהם.
- אתרים משנים מדי פעם את מבנה העמוד ואת הפרסומות. אם הדילוג מפסיק לעבוד, צריך לעדכן את התוסף.
- הורדה מאתרים עלולה לעבור על תנאי השימוש שלהם. הורידו רק תוכן שמותר לכם להוריד.
